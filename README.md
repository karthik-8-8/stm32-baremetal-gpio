# STM32F401RE Bare-Metal GPIO Driver

## Overview
This project focuses on learning bare-metal embedded firmware development
on the STM32F401RE microcontroller using direct register access.

## Hardware
- STM32 NUCLEO-F401RE development board
- STM32F401RE microcontroller

## Development Tools
- STM32CubeIDE
- ARM GCC toolchain
- ST-LINK debugger

## Project Structure
- Inc/       : Header files
- Src/       : C source files
- Startup/   : Startup and vector-table code
- Linker scripts: Flash and RAM memory configuration

## Objective
Understand low-level microcontroller operation, peripheral registers,
GPIO configuration, and embedded firmware development without relying
on high-level peripheral libraries.

## Status
Learning project under development.
